# DataVine

DataVine is a web-based data platform that lets you upload, clean, visualize, and run machine learning models on your data — all in one place, without writing a single line of code.

## Features

- **Data Upload** — Import CSV and Excel files instantly
- **Data Inspection** — Preview your dataset, check column types, spot missing values, and view summary statistics
- **Data Cleaning** — Handle missing values, remove duplicates, rename columns, and drop unwanted features
- **Data Visualization** — Generate charts including bar, line, scatter, histogram, heatmap, and more
- **Model Training** — Train regression, classification, and clustering models on your cleaned data
- **Results Export** — Download cleaned datasets and model outputs
